# 온결의 화면 설계

휴대폰에서 복용 직후의 한 손 체크가 가장 짧은 동선이다. 오늘 화면의 첫 행동은 복약 체크이고, 이미 복용한 약의 체크를 되돌릴 수 있다. 저장되지 않은 값을 실제로 입력된 기록처럼 꾸미지 않는다.

- 과한 대비 대신 미색 바탕, 종이색 목록, 짙은 비취색 글자와 선택 상태를 사용한다. 주요 버튼과 체크·선택 상태는 색 외에도 문자, 위치 또는 체크 마크로 구별한다.
- 언덕과 해가 그려진 정원은 오늘 수첩의 표지에만 쓴다. 기록 상세 화면에서는 본문과 입력 필드에 집중한다.
- 아침·점심·저녁은 시간, 명칭, 아이콘을 함께 표시한다. 컨디션은 그림과 한글 텍스트를 함께 표시하고, 수치는 검사 결과지의 단위를 유지한다.
- 모바일에서는 중요한 메뉴 네 개를 하단에 고정하고 나머지는 더보기에 둔다. 데스크톱에서는 같은 목적지를 왼쪽 탐색 영역에 둔다. 브라우저 뒤로 가기를 지원한다.
- 입력 양식은 키보드 포커스를 제한하는 기본 dialog를 사용한다. 예시 수첩은 시작 전 설명하고 체험 중에 내 수첩으로 돌아가는 단추를 항상 표시한다.
