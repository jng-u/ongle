# 온결
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
사용자가 위임한 선택: React와 Vite 기반 설치형 모바일 웹. 개인 기록에는 서버가 필요 없다.

## Users
크론병을 비롯한 만성 질환을 관리하는 사람이 복용 직후, 하루를 마무리할 때, 병원 방문 전후에 쓴다.

## Product Purpose
언제 어떤 약을 먹었는지, 그날 몸 상태와 검사 경과가 어땠는지를 한 기기에서 기록하고 다시 찾는다.

## Operating Context
복약은 아침·점심·저녁에서 시작해 자유롭게 바꾼다. 캘린더와 당일 체크 목록이 날짜를 공유한다. 검사 항목은 단위와 기준 출처를 분리한다.

## Capabilities and Constraints
사용자가 선택한 저장 정책은 기기 안의 기록과 파일 백업이다. 다른 이용자는 자신의 기기에서 빈 수첩으로 시작한다. 공개 출처에서 검색하는 단어 외에 건강 기록을 전송하지 않는다. 데모와 실제 기록을 섞지 않는다.

## Product Principles
- 처방과 검사지를 옮기는 도구다. 복용량을 추천하거나 수치로 질병을 진단하지 않는다.
- 오늘 복용한 약은 한 번에 체크하고 되돌릴 수 있어야 한다.
- 일정 변경이 과거 기록을 소급해 지우지 않아야 한다.
